# Entrega do protótipo

- `ProjetoAPI`: API REST de Veículos e Serviços com Spring Boot + H2.
- `ProjetoWeb`: aplicação web de Funcionários e Contas do Mês com Spring Boot + Thymeleaf + H2.
- `Apresentacao_Projeto.pptx`: apresentação explicando arquitetura, entidades e execução.

Requisito: JDK 17+ e Maven. Cada projeto é independente e tem instruções próprias no README.
